# Zeron design and GPUI reference

Upstream: [zeronsh/zeron](https://github.com/zeronsh/zeron) at commit `037f4c10d67a38175b2386e776aba54355b4e941` (checked-out `origin` was this repository). All source links below pin that revision so line references stay stable.

Zeron's polish comes from a quiet, nearly monochrome work surface, a clear text ladder, compact controls, and carefully placed chrome. Blur and wallpaper add atmosphere on platforms that support window vibrancy; they do not carry the information hierarchy. For Linux-first MegaMail, the dark surface structure and restrained states transfer well, while the visible shell should paint opaque and reserve window transparency for CSD corner cutouts.

## Hierarchy and state grammar

1. **One deep reading canvas.** In dark mode the content plane is `#060606`; the shell/sidebar is only one step lighter at `#0d0d0d`. Zeron deliberately leaves the conversation flush and unbordered, reserving the single pane divider for the optional right panel. The screenshot reads as a calm page because surfaces are not wrapped in cards by default ([theme.rs:1140-1167](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L1140-L1167), [shell.rs:13170-13175](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L13170-L13175)).

2. **Chrome is quiet; content owns contrast.** Primary text uses neutral lightness `.922`, muted `.708`, and faint `.556`; comments target roughly 17.5:1, 7.5–8:1, and 4.5:1 contrast respectively. Dark hairlines are white at 8%, with a stronger 14% role; hover and selected washes are 11% and 16%. A solid near-white plate with inverse text marks the primary action, while indigo is kept for interactive identity and focus. This keeps selection visible without painting every row as a card ([theme.rs:610-667](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L610-L667), [theme.rs:1158-1188](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L1158-L1188)).

3. **Elevation has a short ladder.** Dark card/dialog/menu planes use `#0e0e0e`, `#101010`, and `#161616` gray steps; pill and input fills have separate tokens. Opaque raised pills brighten on hover in dark mode; light mode darkens the same plate. Borders and shadows, rather than more gray fills, separate white popovers in light mode ([theme.rs:623-647](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L623-L647), [theme.rs:696-711](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L696-L711), [theme.rs:1216-1288](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L1216-L1288)).

4. **Light mode is a role remap.** It uses a white content canvas and a gray shell/sidebar, with white raised surfaces separated by borders and shadows. Dark and light text roles are tuned to similar contrast; the accent moves to a darker value at the same hue so it remains legible on white. The source explicitly warns against mechanically inverting the dark palette ([theme.rs:8-31](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L8-L31), [theme.rs:1216-1269](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L1216-L1269)).

5. **Small controls, generous grouping.** The titlebar is 38px high with a 4px optical top pad; the in-panel header is 44px. Controls are 24px with 14px icons. Back/forward buttons sit 2px apart, then groups get 8px and the identity label gets 12px. The main spacing ladder is 4/8/12/16px. Message bubbles use 16px corners, panels 10px, and small controls 6px ([theme.rs:814-846](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L814-L846), [surface_chrome.rs:7-26](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/surface_chrome.rs#L7-L26), [shell.rs:343-358](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L343-L358)).

6. **Typography stays utilitarian.** Geist is the sans interface face and Geist Mono is used for fixed-width labels and code. The default UI baseline is 16px, with 12/13/14/15/16/18/20px choices; sidebar account text is 13px medium. The default Zeron accent is indigo, `oklch(0.673, 0.182, 276.935)` (sRGB `[124,134,255]`, about `#7c86ff`); warning, danger, and success retain separate amber, red, and emerald semantic roles ([typography.rs:14-42](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/typography.rs#L14-L42), [typography.rs:80-123](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/typography.rs#L80-L123), [theme.rs:87-129](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L87-L129), [theme.rs:2047-2057](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L2047-L2057)).

## Shell and interaction patterns

Zeron uses a 224–400px collapsible sidebar, default 256px, with a 200ms ease-out resize. Its session rows are compact by default (29px); section accordions have no divider rules. Hover reveals row actions while the title, status, and metadata remain readable. The bottom sidebar row groups a 28px account target with a 16px avatar and settings action ([shell.rs:1-12](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L1-L12), [settings.rs:34-36](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/settings.rs#L34-L36), [shell.rs:968-994](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L968-L994), [shell.rs:8964-9014](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L8964-L9014), [sidebar-layout README:11-33](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/docs/screenshots/sidebar-layout/README.md#L11-L33)).

The titlebar overlays the page rather than consuming a separate content row. Its fixed top-left cluster holds sidebar and history controls above the resizing sidebar; the underlying strip remains a drag region, and double-click zooms the window. The macOS cluster reserves space for native traffic lights; Linux/Windows follow their own caption-control paths. Main content can scroll under the titlebar, while columns that cannot underlap add their own 38px top inset ([shell.rs:325-363](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L325-L363), [shell.rs:6464-6524](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L6464-L6524), [shell.rs:13228-13283](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L13228-L13283), [shell.rs:13342-13357](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L13342-L13357)).

For MegaMail, map the same spatial logic to **account/folder sidebar → message list → reading pane**. Keep the reading canvas continuous, put the sender/subject/preview hierarchy inside each row, and use hover/selected washes for row state. Treat compose, search menus, and account popovers as the few raised surfaces. Keep the mail controls and labels native to MegaMail rather than carrying over Zeron's agent-specific icons and copy.

## Platform material and GPUI implementation

Zeron uses a dark/light window tint alpha of 0.80 on macOS and Windows, but 1.0 elsewhere. macOS/Windows can use `WindowBackgroundAppearance::Blurred`; Linux returns `Transparent` so CSD corner cutouts work, while Zeron paints an opaque shell over that window. In-app floating surfaces use a separate GPUI backdrop blur and can still be frosted on Linux. Light mode uses heavier tint coverage because desktop color bleeds through more strongly. Do not make MegaMail's Linux legibility depend on desktop blur or wallpaper; use the solid `#060606`/`#0d0d0d` planes, then apply a small number of scene-level frosted popovers if GPUI Kit's renderer supports them ([theme.rs:787-812](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L787-L812), [theme.rs:914-928](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L914-L928), [theme.rs:1113-1137](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/theme.rs#L1113-L1137), [frost.rs:18-30](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/frost.rs#L18-L30), [frost.rs:72-94](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/frost.rs#L72-L94)).

Zeron is built from GPUI's `Render`/`div` APIs plus its own `Theme` global, shell and small helpers. It depends on `gpui` and `gpui-base` from the Zeron GPUI Component fork ([crates/ui Cargo.toml:70-74](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/Cargo.toml#L70-L74), [THIRD_PARTY_NOTICES.md:16-24](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/THIRD_PARTY_NOTICES.md#L16-L24)). There is no standalone Zeron screen kit to transplant. Keep MegaMail's GPUI Kit buttons, menus, focus states, and popovers; map the surface/type/spacing roles into its existing theme and compose mail-specific panes. Reuse Zeron's window-control code only where MegaMail intentionally takes ownership of Linux CSD behavior.

## Rendering and performance notes

- The sidebar is a separate cached GPUI entity so transcript/caret animation does not rebuild that tree; it is explicitly invalidated for sidebar changes ([shell.rs:1836-1854](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L1836-L1854)). The transcript uses GPUI `ListState` with overdraw, a useful pattern for long message lists ([transcript.rs:64](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/transcript.rs#L64), [transcript.rs:3502-3509](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/transcript.rs#L3502-L3509)).
- Root rendering requests another animation frame only while a tween, hover fade, or state morph is active. Width transitions are manually evaluated and settle exactly at the target; reduced motion snaps them to that state ([shell.rs:6315-6333](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L6315-L6333), [shell.rs:13305-13312](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/shell.rs#L13305-L13312)).
- Repeating loaders that used a frame-rate animation kept the whole window repainting at 120Hz and measured 36% CPU on an M-series laptop. Zeron moved them to one shared 33ms clock (~30fps) that parks when no loader is mounted. Mail sync indicators should follow that pattern: animate only while syncing, and throttle low-detail pulses ([motion.rs:49-63](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/motion.rs#L49-L63)).
- Zeron's image-memory plan flags encoded attachment bytes without eviction and estimates decoded RGBA + atlas tile + encoded data at about 2.5× decoded image size. MegaMail should bound attachment decode/thumbnail caches and release GPUI image assets when rows or messages leave the active view ([memory-plan.md:57-64](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/docs/memory-plan.md#L57-L64)).
- Backdrop blur wraps the entire popup subtree in one GPUI scene layer so the blur, border, contents and hit layers keep their paint order; the shared menu blur radius is 16px. Reuse one layer per frosted surface instead of nesting extra blurred surfaces ([frost.rs:1-30](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/frost.rs#L1-L30), [frost.rs:72-94](https://github.com/zeronsh/zeron/blob/037f4c10d67a38175b2386e776aba54355b4e941/crates/ui/src/frost.rs#L72-L94)).
