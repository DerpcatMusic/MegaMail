The appeal comes from a quiet work plane, a narrow navigation index, restrained row states, and one persistent action surface. The wallpaper and blur add atmosphere on supported desktops; the hierarchy is already clear without them.

State grammar

What carries the signal
RestPrimary label at reduced text strength
HoverWash + brighter text; row action appears
SelectedOne rounded fill; no row outline
StatusSmall icon/dot; semantic status color
Not an observed mail rule: Zeron’s selected rows do not become bold. Its sidebar shows task activity, not unread mail. MegaMail must add unread emphasis as an email-specific state and keep it distinct from Working, Done, Queued, and Failed.

Linux-first material rule

Make the hierarchy work on an opaque window first. Zeron sets the main window tint fully opaque on Linux because compositor blur is not guaranteed. Its GPUI scene can still frost floating surfaces such as popovers and the composer when that renderer is available. A transparent GPUI window-background setting is used for CSD corner cutouts; the painted app plane remains opaque.
