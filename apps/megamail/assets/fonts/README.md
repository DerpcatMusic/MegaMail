# Bundled typefaces

The Geist Regular, Medium, and SemiBold faces are unmodified files from
[Vercel's Geist font project](https://github.com/vercel/geist-font), copied
from Zeron source commit `037f4c10d67a38175b2386e776aba54355b4e941` at
`crates/ui/assets/fonts/`. Geist is copyright 2024 The Geist Project Authors.

in [licenses/Geist-OFL.txt](licenses/Geist-OFL.txt).
